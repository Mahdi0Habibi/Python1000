## 📚 دربارهٔ کتاب

> **«حل المسائل پایتون»** کتابی جامع و پروژه‌محور است که مفاهیم برنامه‌نویسی پایتون را از طریق صدها مثال و تمرین طبقه‌بندی‌شده آموزش می‌دهد. این کتاب از مباحث مقدماتی شروع می‌شود و به تدریج به موضوعات پیشرفته‌تری مثل **ساختمان داده**، **برنامه‌نویسی شیءگرا** و **کار با NumPy** می‌رسد.
